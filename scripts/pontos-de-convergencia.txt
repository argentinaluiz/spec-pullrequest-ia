# Os pontos de convergência: arquivos em que duas frentes paralelas costumam esbarrar, em quatro tipos. É o
# dono único desta classificação: o scripts/frentes.sh a lê para separar os conflitos do `listar`, e a
# skill /sincronizar a lê para saber o que resolver por regra. Este arquivo só classifica; a regra de cada
# tipo é da /sincronizar.
#
# Uma linha por padrão: o tipo, uma tabulação e o caminho, relativo à raiz do repositório, que aceita `*`
# (casa também barras). Vale o primeiro padrão que casa. Um arquivo que nenhum padrão casa é código e pede
# atenção.
#
# Só os três primeiros tipos têm regra mecânica; os documentos a pessoa junta à mão.
#
#   gerado       o snapshot da OpenAPI, regenerado a partir do código mergeado
#   migracoes    o schema do Prisma e a pasta de migrações
#   registros    as listas em que cada frente acrescenta um item, em ordem alfabética
#   documentos   os documentos do projeto
